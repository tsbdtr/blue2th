# Tech stack

Versions are not copied here: read the manifest that pins them.

- Rust, cargo workspace, `resolver = "2"`. Members and shared deps: root `Cargo.toml`. Per-crate deps: `<crate>/Cargo.toml`. Lockfile tracked.
- No `rust-toolchain.toml`. CI pins the compiler in `.github/workflows/ci.yml` and `release.yml` (`toolchain:` key); a newer or older local `rustc` makes clippy disagree with CI.
- **server**: Axum on Tokio; BlueZ through `bluer`; PipeWire through the native loop in `graph_pw.rs`; `librespot` spawned as a child process.
- **mobile**: Dioxus 0.7 for Android, built with `dx`; HTTP via `reqwest`; Tailwind CSS generated by `dx` from `blue2th-frontend/tailwind.css`; JNI only in `jni_util.rs` and `lifecycle.rs`.
- **proto**: `serde` only.
- Discovery: `mdns-sd`, shared by server (publishes) and app (browses).
- Lint/format/licence config: `clippy.toml`, `rustfmt.toml`, `deny.toml` (licence allowlist, checked in CI by `cargo deny`).
- Hooks in `.githooks/` (opt-in through `core.hooksPath`); CI in `.github/workflows/`.
- Licence: `MIT OR Apache-2.0`, declared once in `[workspace.package]`.
